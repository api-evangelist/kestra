Kestra 0.13.0 ships with tenants, a full Visual Studio Code built into the UI, and a new improved navigation bar. This release is packed with new integrations including Ansible, Arrow Fight, ClickHouse, CloudQuery, Dataform, Discord, Dremio, GoogleChat, Modal, OpsGenie (Atlassian), Pagerduty, SendGrid, Sentry, SQLite, SQLMesh, Terraform, Twillio, Weaviate, WhatsApp, and Zenduty.
